# 2026-11-08 v1.1 — 반응 곡면 · RBFNN · 모델 사용법

## 한 일
기획자 원광재 요청 3건(11-07)을 반영했다.

1. **반응 곡선 → 반응 곡면** — 새 단계 「5. 반응 곡면」. 설계인자 두 개를 X·Y 축으로 고르면(처음엔 영향도 상위 두 인자) 예측을 Z 높이와 색(viridis)으로 그린다. 나머지 인자는 막대 + 숫자 칸으로 고정값을 정하고 바꾸면 곧바로 다시 계산한다. 마우스로 끌어 돌리기, 처음 보기·위에서 보기·확대·축소·PNG 저장. 곡면 위에 올리면(휴대폰은 누르면) 그 점의 값 + GP 는 ±1σ. 「고정값을 1순위 최적 조건으로」를 누르면 빨간 점으로 최적점 표시. 인자가 하나뿐이면 예전 반응 곡선을 그린다.
   - 그리기는 build-2611-04 surface 와 같은 방식(정사영 + 먼 칸부터 칠하기, 캔버스, 라이브러리 없음). 정사영·색·다각형 안 판정·격자 예측은 엔진(`project`·`colormap`·`pointInPoly`·`surfaceGrid`).
2. **모델 JSON 사용법** — 파일 맨 앞 `_사용법` 칸: 설명, 입력 순서(이름 · 원래 단위 그대로 · 학습 범위), 출력, 계산 순서 5단계, 표준편차 안내, 예시(데이터 평균 입력 → 결과), JavaScript·Python 코드(줄 배열). 저장 형식 version 2 에 `modelType`, GP `alpha`, RBFNN `centers`·`weights` 추가. v1.0 파일도 그대로 읽는다.
3. **RBFNN 모델** — 왼쪽 메뉴(넓은 화면은 왼쪽 고정, 좁으면 위)에서 GP / RBFNN 선택. 엔진 `kmeans`(k-means++ · 시드 2611) · `rbfFit`(가우시안 기저 + 절편, 릿지) · `train(type)`. 하이퍼파라미터 중심 수 k(정수)·폭 σ·규제 λ, 기본 4×5×3 = 60, 검증 R² 로 선정(동률이면 실제 중심 수 적은 쪽 → λ 큰 쪽). 모델 비교·예측-실측·잔차·파레토·Grid Search·곡면·저장·엑셀 모두 두 모델에서 돈다. σ 는 GP 전용이라 RBFNN 화면·엑셀·저장 파일에 그렇게 적었다. 종류를 바꿨다가 돌아오면 그 종류의 결과를 되살리고, 두 모델의 검증 R² 를 왼쪽 메뉴에서 견준다.
