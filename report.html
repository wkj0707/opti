3. 기능과 시험

기획서의 기능 8가지와 시험 189개입니다.

기능내용
모델 종류 고르기(v1.1)왼쪽 메뉴에서 GP 모델 또는 RBFNN 모델을 고릅니다. 같은 흐름(학습·비교·최적화·곡면·저장)이 두 모델 모두에서 돌고, 두 모델의 검증 R² 를 메뉴에서 견줍니다. 예측 표준편차는 GP 전용입니다.
데이터 입력편집 표에 직접 적거나 CSV·엑셀을 불러옵니다. 숫자 아닌 칸·빈 칸이 있는 행은 빼고 몇 행의 어느 열 때문인지 보여 줍니다.
학습 설정학습 비율·시드와 하이퍼파라미터 3종(GP: ℓ·σf·σn · RBFNN: 중심 수 k·폭 σ·규제 λ)의 최소·최대·개수를 정하면 조합 수를 먼저 보여 줍니다.
모델 비교·선정모든 조합의 학습·검증 R², RMSE, 로그 주변우도를 표로 보여 주고 검증 R² 최대 모델을 자동으로 고릅니다. 행을 눌러 바꿀 수 있습니다.
평가 그래프예측값-실측값, 잔차, 하이퍼파라미터별 최고 검증 R², 설계인자 영향도 파레토를 SVG 로 그립니다.
Grid Search인자별 범위·간격으로 모든 조합을 예측해 최대·최소·목표값 기준 상위 10개 조건과 표준편차, 학습 범위 밖 여부를 보여 줍니다.
반응 곡면(v1.1)설계인자 두 개를 X·Y 축으로, 예측을 Z 높이와 색으로 그린 3D 곡면. 마우스로 돌리고, 나머지 인자는 막대·숫자 칸으로 고정, 올리면 값(GP 는 ±1σ)이 나옵니다. 외부 라이브러리 없이 캔버스에 직접 그립니다.
저장·내보내기모델 JSON 저장·불러오기 — 파일 맨 앞 _사용법 칸에 입력 이름·순서·단위, 계산 순서, JavaScript·Python 예시 코드. 엑셀(데이터·모델비교·검증예측·최적조건) 내보내기.

  • v1.0 (2026-11-03) — 첫 판 — 데이터 입력·GPR 하이퍼파라미터 비교·평가 그래프·Grid Search·모델 저장·엑셀 내보내기; 기획서 워드 판·파이프라인·아키텍처·와이어프레임 추가

6. 한계와 남은 일

  • 브라우저 안 계산이라 수백 행 규모에 맞춰 두었습니다(수천 행 이상은 느려집니다).
  • 하이퍼파라미터는 정해진 범위의 격자 탐색만 합니다(인자별 길이 척도·경사 기반 최적화 없음). RBFNN 은 예측 표준편차를 내지 않습니다.
  • 범주형(글자) 설계인자와 결과값 여러 개 동시 최적화는 하지 않습니다.
  • 예측값은 모델 추정이며 확인 실험이 필요합니다.
  • 업무 자료는 지금처럼 브라우저 안에서만 처리합니다. 로그인 DB 에는 「누가 쓸 수 있는가」와 게시판 글만 있습니다.
  • 로그인 뒤 화면(게시판 · 관리 · 첫 화면 고르기)은 실제 계정으로 눌러 보지 않았습니다. 가입 → 사용 신청 → 승인 → 게시판 글쓰기 확인은 기획자와 관리자 몫입니다.
  • 독립 운영까지 남은 것: 본인 Supabase 프로젝트에 auth.sql · board.sql · site.sql 실행 → js/auth-config.js 의 url · anonKey 교체 → 다시 배포(supabase/README.md)
