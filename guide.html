사용법

실험 데이터 한 장으로 예측 모델과 최적 조건을 찾습니다

왼쪽 메뉴에서 모델 종류(GP · RBFNN)를 고르고, 데이터 넣기 → 학습 설정 → 모델 비교 → 최적 조건 탐색 → 반응 곡면 → 저장 순서로 진행합니다. 계산은 전부 이 브라우저 안에서 끝나고 파일은 어디로도 올라가지 않습니다.

1. 데이터

행 하나가 Run(실험·해석 1회)이고, 열은 설계인자와 결과값입니다. 첫 줄은 열 이름입니다.

Run온도(℃)압력(bar)시간(분)강도(MPa)
R012179.82359.04
R022082.35756.83

CSV(UTF-8 · 엑셀이 저장한 한글 CSV 모두) 와 엑셀 첫 시트를 읽습니다. 엑셀에서 여러 칸을 복사해 표에 붙여넣어도 됩니다.

숫자가 아닌 칸이나 빈 칸이 있는 행은 학습에서 빼고, 몇 행의 어느 열 때문인지 화면에 보여 줍니다. Run 열 · 목표(결과값) · 설계인자는 표 아래에서 고릅니다. 결과 열이 여러 개면 목표로 하나를 고르고 나머지는 설계인자에서 빼세요.

2. 학습 설정과 하이퍼파라미터

학습 비율(기본 80%)만큼 Run 을 무작위로 골라 학습에 쓰고, 나머지로 검증합니다. 시드가 같으면 늘 같은 Run 이 검증으로 갑니다.

모델은 가우시안 프로세스 회귀(GPR)이고 RBF 커널을 씁니다. 입력과 출력은 평균 0 · 표준편차 1 로 표준화한 뒤 학습합니다.

  • 길이 척도 ℓ — 클수록 완만한 곡면을 그립니다. 너무 작으면 Run 사이를 들쭉날쭉하게 잇습니다.
  • 신호 크기 σf — 결과값이 평균에서 벗어나는 정도입니다.
  • 노이즈 σn — 같은 조건에서도 생기는 측정 잡음입니다. 너무 작으면 잡음까지 외워 과적합합니다.

세 값마다 최소 · 최대 · 개수를 적으면 로그 간격으로 나눈 모든 조합의 모델을 만듭니다(기본 5 × 3 × 3 = 45개).

RBFNN 모델을 고르면

RBFNN(방사 기저 함수 신경망)은 표준화한 입력 공간에 중심 k 개를 두고(학습 Run 을 k-평균으로 묶은 중심, k 가 학습 Run 수 이상이면 학습 Run 전부), 중심에서 멀어질수록 작아지는 종 모양 함수 φ = exp(−거리² ÷ (2σ²)) 들을 더해 결과를 냅니다. 더하는 가중치는 릿지 회귀로 구합니다.

  • 중심 수 k — 은닉층 뉴런 수입니다. 많을수록 굴곡을 잘 따라가지만 과적합하기 쉽습니다. 최소~최대를 고르게 나눈 정수로 시험합니다.
  • 폭 σ — 중심 하나가 영향을 미치는 거리입니다. 클수록 완만합니다.
  • 규제 λ — 가중치를 작게 누르는 정도입니다. 클수록 과적합을 덜 합니다.

기본 4 × 5 × 3 = 60개 조합을 같은 방식(검증 R²)으로 비교합니다. RBFNN 은 예측 표준편차(±σ)를 내지 않습니다 — 불확실성은 GP 모델로 확인하세요. 두 모델을 다 학습하면 왼쪽 메뉴에 각각의 검증 R² 가 나와 견주어 볼 수 있고, 메뉴를 바꾸면 그 모델의 결과가 되살아납니다.

3. 모델 비교 · 선정

검증 R² 가 가장 큰 모델을 자동으로 고릅니다. 같으면 GP 는 로그 주변우도(데이터를 얼마나 잘 설명하는지)가 큰 쪽, RBFNN 은 실제 중심 수가 적은 쪽(더 단순한 모델)입니다. 표의 다른 행을 누르면 그 모델로 바뀝니다.

R² = 1 − (잔차 제곱합 ÷ 실측의 평균 대비 제곱합)입니다. 1 에 가까울수록 좋고, 0 이면 평균으로 찍은 것과 같습니다. 예측값-실측값 그래프는 점이 y = x 선에 붙을수록, 잔차 그래프는 0 주위에 고르게 흩어질수록 좋습니다.

파레토 차트는 한 인자만 데이터 범위 안에서 바꿀 때 예측이 움직이는 폭입니다(다른 인자는 데이터 평균에 고정). 인자끼리 함께 작용하는 효과는 다 담기지 않습니다.

4. 최적 조건 탐색

최적화에는 고른 하이퍼파라미터로 학습+검증 데이터 전체를 다시 학습한 모델을 씁니다. 인자마다 최소 · 최대 · 간격을 적으면 모든 조합의 예측을 계산해 상위 10개 조건을 보여 줍니다. 조합이 20만 개를 넘으면 간격을 넓히도록 멈춥니다.

목표는 최대화 · 최소화 · 목표값에 가깝게 중에서 고릅니다. 예측 표준편차가 크면 그 근처에 데이터가 적다는 뜻입니다. 학습 데이터 범위 밖 조건에는 「범위 밖」 표시가 붙습니다 — 외삽이라 믿음직하지 않습니다.

예측값은 모델 추정이며 확인 실험이 필요합니다.

5. 반응 곡면

설계인자 두 개를 X 축 · Y 축으로 고르면 결과값 예측을 높이(Z)와 색(낮음 보라 → 높음 노랑)으로 그립니다. 처음에는 영향도가 큰 두 인자가 골라져 있습니다. 고르지 않은 인자는 막대나 숫자 칸으로 값을 정하면 그 값에 고정해 곡면을 다시 계산합니다. 「고정값을 1순위 최적 조건으로」를 누르면 최적 조건 주변을 보고, 빨간 점이 1순위 조건입니다.

그림을 마우스로 끌면 돌아가고, 곡면 위에 마우스를 올리면(휴대폰은 누르면) 그 점의 값이 나옵니다. GP 는 ±1σ 도 함께 나오고 RBFNN 은 σ 가 없습니다. 「그림 저장(PNG)」으로 내려받을 수 있습니다.

6. 저장 · 내보내기

모델 저장(JSON)에는 표준화 계수 · 하이퍼파라미터 · 학습 데이터가 들어 있어 다시 불러오면 같은 예측을 냅니다. 파일 맨 앞 _사용법 칸에 넣을 입력의 이름 · 순서 · 단위(원래 단위 그대로, 학습 범위), 결과를 계산하는 순서, 바로 붙여 쓸 JavaScript · Python 코드와 예시(입력 → 결과)를 적어 둡니다. 다른 프로그램에서 이 파일만으로 예측을 낼 수 있습니다(GP 는 평균만 — σ 는 이 도구에서 불러와 보세요). 엑셀 내보내기는 데이터 · 모델비교 · 검증예측 · 최적조건 네 시트입니다.

7. 이번 판에서 하지 않는 것

  • 수천 행 이상의 큰 데이터 — 브라우저 안에서 계산하므로 수백 행 규모에 맞춰 두었습니다.
  • 인자마다 다른 길이 척도(ARD) · 다른 커널 · 경사 기반 하이퍼파라미터 최적화 — 정해진 범위의 격자 탐색만 합니다.
  • 범주형(글자) 설계인자 — 숫자 인자만 씁니다.
  • 결과값 여러 개를 동시에 최적화하는 다목적 최적화.
